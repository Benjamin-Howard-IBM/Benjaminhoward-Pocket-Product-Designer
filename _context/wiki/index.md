## Quick orientation

- **This repo is a personal tool.** Pocket Product Designer (PPD) is a scaffold Benjamin built for himself to run a structured product design pipeline: Frame → Map → Design → Ship.
- **PPD currently runs three independent, unrelated active projects.** MCSP is Vault on MCSP (FedRAMP) - a managed, FedRAMP-compliant Vault offering on IBM's Multi-Cloud SaaS Platform. Azure Peering-vWAN is native Azure Virtual WAN / Secure Virtual Hub connectivity support for HCP Vault Dedicated. HVD Gateway is a CSP-agnostic WireGuard-based connectivity gateway for HCP Vault Dedicated. Do not mix context between them.
- **Benjamin owns design and research end-to-end** - foundational research, evaluative research (usability testing), and UI design. Solo contributor.
- **Default collaboration mode is think-through-first.** Do not drop finished work without discussion unless Benjamin explicitly asks for it.
